# 📈 Financial Forecasting Project

> **Business Analyst Internship Project**

A comprehensive financial forecasting project that predicts future business performance using historical financial data. The project combines **Python**, **Machine Learning**, **Excel**, and **Power BI** to forecast Revenue, Expenses, Profit Before Tax (PBT), and Profit After Tax (PAT), enabling data-driven business decision-making.

---

# 📌 Project Overview

Organizations rely on financial forecasting to estimate future performance, optimize budgeting, identify growth opportunities, and support strategic planning.

This project analyzes historical financial statements, cleans and preprocesses the data, builds forecasting models using Linear Regression, and presents the results through an interactive Power BI dashboard.

---

# 🎯 Business Problem

Business leaders need reliable estimates of future financial performance to make informed strategic decisions.

This project addresses the following questions:

- How is revenue expected to grow?
- How will operating expenses change?
- What is the projected Profit Before Tax?
- What is the projected Profit After Tax?
- What financial insights can support better decision-making?

---

# 🎯 Objectives

- Forecast future Total Income
- Forecast Total Expenses
- Predict Profit Before Tax (PBT)
- Predict Profit After Tax (PAT)
- Visualize financial trends
- Support business planning and budgeting

# 📊 Dataset

The dataset contains historical financial statement information including:

- Year
- Total Income
- Total Expenses
- Profit Before Tax
- Profit After Tax

### Data Source

Company Annual Reports (Audited Financial Statements)

> **Note:** The financial statements include revised comparative figures where applicable. The FY2023 Annual Report restates FY2022 comparative figures rather than providing a separate observation for this forecasting dataset. Therefore, the dataset reflects the available audited financial information.

#  Forecasting Methodology

The project uses **Linear Regression** for financial forecasting.

### Why Linear Regression?

- Simple and interpretable model
- Suitable for small historical datasets
- Captures long-term financial trends
- Provides baseline forecasts for business planning

The model predicts:

- Total Income
- Total Expenses
- Profit Before Tax
- Profit After Tax

Forecast Period:

- 2027
- 2028
- 2029
